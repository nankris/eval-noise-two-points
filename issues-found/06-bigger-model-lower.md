# The bigger model scored lower

On the same 1,000 AG News items with the same corrected prompt, Qwen3-1.7B scored 82.1% and Qwen3-0.6B 84.5% (paired −2.4 pp, 95% CI −5.2 to +0.3, which includes 0). The prompt was tuned on 60 train items with the 0.6B model only, and the 1.7B run used bf16. This is descriptive, not a registered test. Don't read it as 'smaller is better'.
