# v3b ran in a different precision

v3b loaded Qwen3-1.7B in bfloat16 on CPU (amendment logged at 21:40 IST, before any v3b result) because the shared box lacked RAM for fp32. The 0.6B arms ran in fp32. The precision difference can shift individual predictions, so the 0.6B-vs-1.7B accuracy comparison mixes model size with precision.
